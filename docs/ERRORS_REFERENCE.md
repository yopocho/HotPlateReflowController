## Error Codes
| Code | Message | Recoverable |
|----- | -----| ----- |
| 0x00 | No errors | N/A |
| 0x01 | TC shorted to GND | Yes |
| 0x02 | TC shorted to Vcc | Yes |
| 0x03 | TC error (unknown) | Yes |
| 0x04 | No TC detected | Yes |
| 0x05 | No ZCD detected | Yes |
| 0x06 | Max. temp. exceeded! | Yes |
| 0xF0 | No heater detected | No |
| 0xF1 | No display detected | No |
| 0xF2 | No I-trans. detected | No |
| 0xF3 | No comm. with I-trans. INA219 | No |
| 0xF4 | No fan detected | No |
| 0xF5 | No comm. with fan INA219 | No |
| 0xF6 | No comm. with TC amp. | No |
| 0xF7 | No encoder detected | No |
| 0xF8 | Overcurrent event (>4A)! | No |
